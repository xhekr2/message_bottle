검증 일자: 2026-11-11 13:57~14:11
기기 또는 브라우저: Android 에뮬레이터 Pixel 9 (Android 17, API 37, 1080×2424, 글자 크기 1.0). 실제 휴대폰과 두 대 동시 접속은 하지 않았다.
API 기본 주소: 앱은 `http://10.0.2.2:8080`(에뮬레이터에서 본 서버 PC), PC에서 직접 호출할 때는 `http://localhost:8080`. 둘은 같은 서버다.
문서·코드 버전 또는 커밋: git 저장소가 아니어서 커밋이 없다. 앱 버전 1.0.0+1, 2026-11-11 14:05에 빌드한 디버그 APK(빈 검색 결과 안내를 고친 뒤의 코드). 11번 이전 화면은 13:56 빌드에서 찍었다.

## Postman·DB·앱의 같은 자료

Postman 대신 `curl`로 같은 요청을 보냈고, DB는 H2가 아니라 MySQL(`message_bottle`)이다.

실제 응답 ID: 편지 `22` (보관 뒤 보관 `archiveId` `8`)
Postman 요청·응답 근거: `evidence/api-01-send.txt`(발송 응답 `{"id":22,"receiverUsername":"ichk01","anonymous":false,"sentAt":"2026-11-11T13:57:21.131865"}`, 201), `evidence/api-02-inbox-sent-sea.txt`(받은 편지함 응답의 `archiveId 8 / letterId 22 / senderUsername ichk02 / preview integration check letter one`)
H2 조회 결과 근거: `evidence/db-01-after-archive-and-send.txt` (`letters.id 22`, 보낸 사람 `ichk02`, 받는 사람 `ichk01`, 내용 `integration check letter one`, 상태 `ARCHIVED`, `sent_at 2026-11-11 13:57:21.131865`, `letter_archives.id 8`)
앱 화면 근거: `evidence/04-letter-open.png`(연 편지), `evidence/08-inbox.png`(받은 편지함 카드)
서로 같은 값 / 다른 값:
- 같은 값: 편지 id, 보낸 사람, 받는 사람, 내용, 발송 시각, 보관 id, 보관 여부.
- 표시만 다른 값: 발송 시각은 API·DB에서는 마이크로초까지, 앱에서는 "11월 11일"로 보인다. 앱 화면에는 id가 보이지 않는다.
- API 응답에 없는 값: DB의 `status`, `opened_at`, `expires_at`은 서버만 쓰고 응답에 넣지 않는다.
- 같은 방식으로 앱에서 보낸 편지 `26`도 앱 화면(`17-sent-box.png`), API(`api-02-inbox-sent-sea.txt`의 `/api/sent`), DB가 같았다.
- `db-01` 파일의 `anon`·`replied` 열은 BIT 값이 글자로 찍혀 비어 보인다. `db-02`부터는 0/1로 찍었다.

## 남은 문제

| 문제 | 재현 조건 | 영향 | 다음 확인 방법 |
|---|---|---|---|
| 답장, 10개 초과 대기, 공유 바다(낚기·띄우기·답장), 바다 공개 설정과 방문은 기기에서 해 보지 않았다 | 해당 없음 (자동 테스트로만 확인: 앱 132개는 오늘 수정 후 다시 돌려 통과, 서버 61개는 직전 실행에서 통과했고 그 뒤 서버 코드는 바꾸지 않았다) | 실제 화면에서의 문제를 놓칠 수 있다 | 같은 방법으로 에뮬레이터에서 순서대로 해 본다 |
| 실제 휴대폰, 같은 LAN의 기기 2대 동시 사용을 확인하지 않았다 | 서버 PC의 LAN IP로 빌드(`--dart-define=API_BASE_URL=...`)해 두 기기에서 접속 | 발표 환경에서 접속이 안 될 수 있다 | 발표 장소 네트워크에서 두 기기로 주고받기 |
| 서버가 꺼졌을 때와 목록 읽기 실패의 [다시 시도]는 기기에서 보지 않았다 | 서버를 끄고 바다·편지함 열기 | 안내 문구가 실제로 어떻게 보이는지 모른다 | 확인용 서버를 따로 띄워 끄고 켜며 확인 |
| 5초 동안 조작이 없으면 바다의 버튼이 숨고, 숨은 상태의 첫 터치는 버튼을 다시 보이게만 한다 | 내 바다에서 5초 이상 기다린 뒤 버튼 자리를 한 번 누름 | 설계된 동작이지만 처음 쓰는 사람은 버튼이 안 눌린다고 느낄 수 있다. 자동 조작 도구는 두 번 눌러야 한다 | 사용자에게 보여 주고 대기 시간·동작을 정한다 |
