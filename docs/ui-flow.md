# 화면 목록과 흐름 — Message Bottle (유리병 편지)

## 1. 화면 목록

S01 내 바다가 메인 화면이다. 편지 쓰기는 S01 위에 바텀시트로 열리고, 보낸/받은 편지함은 S01 위의 팝업으로 열린다. 편지 내용은 상세 화면(S05, detail_screen)에서 확인한다.

| 화면 ID | 이름 | 목적 | 요구사항 | 새 설계 범위 |
|---|---|---|---|---|
| S00 | 공통 로그인 | 로그인 후 개인 앱으로 진입 | R05 | 제공 화면 연결 |
| S01 | 내 바다 (메인) | 떠 있는 유리병 조회, 편지 쓰기·편지함 열기 시작 | R01, R02, R03, R04, R05 | 업무 화면 1 |
| S02 | 편지 쓰기 (바텀시트) | 우하단 FAB로 열어 받는 사람 검색·선택, 내용·익명 여부 입력 후 발송 (등록 전용, 수정 모드 없음) | R02, R05 | 업무 화면 2 |
| S03 | 보낸 편지함 (팝업) | 보낸 편지 목록 조회(길면 스크롤), 삭제 기능 없음 | R01, R04, R05 | 보조 화면 |
| S04 | 받은 편지함 (팝업) | 보관한 편지 목록 조회(길면 스크롤), 카드를 슬라이드해 삭제 | R01, R04, R05 | 보조 화면 |
| S05 | 편지 상세 (detail_screen) | 편지 내용 확인. 바다에서 연 일반 편지는 우상단 X(영구 삭제)와 하단 [답장], [보관] 제공. 익명 편지는 [보관]만 | R01, R03, R04, R05, R06 | 보조 화면 |

## 3. 흐름 검토

- [ ] 등록에서 시작하여 결과를 목록에서 확인할 수 있다. (발송 후 보낸 편지함에서 확인)
- [ ] 수정 모드는 없고, S02는 등록 모드만 있다. 보관과 삭제의 버튼 문구·색이 구분된다.
- [ ] 취소·실패·삭제 취소 후 도착 상태가 정해져 있다.
- [ ] 미로그인·타인 자료·대상 없음의 다음 행동이 정해져 있다.
- [ ] 답장에서 돌아가면 임시 저장되고, 다시 답장할 때 불러오기·새로 쓰기를 고를 수 있다.
- [ ] 답장을 보내면 원본이 받은 편지함에 보관되고 체크 아이콘으로 구분된다.

## 4. 다음 장에 남길 질문

- 공개 바다 방문자가 편지를 열어 볼 수 있게 할지(requirements.md Q17, 보류). 정해지면 S07에 닫기만 있는 편지 보기가 추가된다.
- 열람 후 이탈(requirements.md Q15)과 서버 반영 전 앱 종료(Q16)는 정해졌다. 앱이 종료된 뒤 다시 시작해 바다를 불러올 때 처리되지 않은 편지를 버리고, 서버가 확인해 주기 전에 종료되어도 구제하지 않는다.
- 바다에서 연 편지 상세에서 Android 뒤로 가기를 "아무 일도 하지 않음"으로 해석한 것이 맞는지 (Q9).
- 바다가 가득 찬 상태에서 보낸 편지가 "대기"임을 발신자에게 알릴지 여부. 현재 설계에는 표시하지 않는다.
