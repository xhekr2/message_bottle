| 구분 | 내용 |
|---|---|
| 제공 자료 (그대로 두고 참고만 함) | 문서 양식(요구사항·화면 흐름·디자인 기준·화면명세·검증 기준, 데이터 설계, 디자인 연결·통합 확인), 포트폴리오 양식(`002_포트폴리오양식`), 찾아줘 작성 예시(`003_작성예시`) |

| 직접 만든 부분 | 주제와 규칙(유리병 편지, 10개 수용·대기, 7일 만료, 열람 후 이탈, 공유 바다 등), 앱 코드(`message_bottle_frontend`)와 서버 코드(`message_bottle_backend`) 전체, MySQL 구성(예시는 H2), 디자인 시안 3개, 위 문서들의 내용 |
| 예시 코드 사용 여부 | 프로젝트 소스에서 찾아줘 예시의 코드(게시물·`app_users`)는 찾지 못했다(2026-11-11 검색) |
