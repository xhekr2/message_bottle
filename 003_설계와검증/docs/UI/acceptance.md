# 검증 기준 — Message Bottle (유리병 편지)

설계 검토는 문서와 시안에 조건이 표현되었는지를 확인한다. 실행 검증은 실제 앱·서버·DB를 대상으로 한다. 아직 구현하지 않은 항목은 실행 검증에 `미실시`라고 적는다.

AC01~AC12는 템플릿의 번호를 유지하고 내용을 이 앱에 맞췄다. AC13~AC28은 이 앱에서 추가한 기준이다.

## 남은 질문

- 미표현·미확정 조건은 requirements.md의 질문 표에 있다. 열람 후 이탈(Q15)과 서버 반영 전 앱 종료(Q16)는 정해졌다. 앱이 종료된 뒤 다시 시작할 때 판단하고, 서버가 확인해 주기 전에 종료되어도 구제하지 않는다. AC19는 앱 종료·재시작 기준으로 검증하고, 홈 버튼·전화 등 앱이 살아 있는 동안은 편지가 유지되는지도 확인한다. 바다에서 연 편지에서 Android 뒤로 가기를 "아무 일도 하지 않음"으로 해석한 점(Q9)은 확인이 필요하다.
- 설계 검토는 모든 항목이 미검토이고 실행 검증은 모두 미실시다. 구현한 로그인·가입 API는 별도로 확인했으나 이 표의 항목으로 환산하지 않았다.
- 디자인 값은 제안값이므로 시안에서 명암비와 조작 크기를 확인한 뒤 AC12를 검토한다.
