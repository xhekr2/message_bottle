# 디자인 기준 — Message Bottle (유리병 편지)

> 색은 사용자가 시안을 보고 확정했다(2026-11-10). 글자 크기·간격 등은 제안값이며, 명암비는 아직 측정하지 않았다. 시안: `docs/mockup/index.html`.

## 1. 시각 방향

맑은 바다: 푸른 계열을 기본으로 한다. 바다 화면은 연한 물빛에서 깊은 파랑으로 이어지는 바탕에 유리병이 떠 있고, 편지 상세는 종이 편지를 읽는 것처럼 따뜻한 종이색 바탕을 쓴다. 다른 스타일을 함께 쓰지 않는다. 파도·빛 반사·유리병 부유 움직임은 과하지 않게 둔다.

## 3. 글자·간격·형태

| 항목 | 기준 | 확인 방법 |
|---|---|---|
| 제목 | 22sp, 굵게 | 화면 폭이 좁은 기기에서 읽기·잘림 |
| 본문 | 16sp, 편지 내용은 줄 간격 1.5 | 긴 문장·글자 확대 상태에서 줄바꿈 |
| 보조 설명 | 13sp | 배경 위 대비·읽기 |
| 간격 | 8의 배수 단위 (8·16·24) | 요소 간 분리, 바다 화면에서 유리병끼리 겹치지 않는지 |
| 모서리 | 버튼·입력 칸 12, 시트·팝업 위쪽 모서리 24 | 화면 간 일관성 |
| 터치 영역 | 최소 48×48 논리 픽셀 | 우상단 편지함 버튼, FAB, X 버튼을 실제 조작 |

## 4. 컴포넌트와 상태

| 요소 | 용도·문구 | 기본·선택·비활성 | 오류·처리 중 |
|---|---|---|---|
| 주요 버튼 | "보내기", "로그인" | 기본: 주요 행동 색 / 비활성: 입력이 비었을 때 흐리게 | 오류: 입력 오류 안내 후 활성 유지 / 처리 중: 스피너로 바꾸고 다시 누를 수 없음 |
| 보조 버튼 | "취소", "다시 시도", [보관] | [보관]은 강조 색 + 책갈피 아이콘 | 처리 중: 스피너, 중복 누름 방지 |
| 입력 칸 | 라벨 "받는 사람 검색", "편지 내용" / 도움말: 아이디는 대소문자를 구분한다. 검색 결과는 입력 칸 아래 목록으로 보여주고 선택하면 선택된 사용자로 표시 | 기본·포커스 윤곽선 / 처리 중 비활성 | 오류 문구를 입력 칸 바로 아래에 오류 색으로 표시 |
| 목록 카드 | 편지함 한 줄: 상대 아이디(익명이면 "익명") → 발송일 → 내용 앞부분 | 선택 시 상세 이동 / 눌림 표시. 받은 편지함 카드는 답장한 편지에만 맨 오른쪽에 강조 색 원 안의 체크 아이콘을 둔다. 슬라이드하면 뒤에 오류 색 바탕, 휴지통 아이콘, "삭제" 문구가 나타난다 | 대상 없음(이미 삭제·만료): 안내 후 목록 갱신. 슬라이드 삭제 실패: 카드 복귀와 안내 |
| 유리병(바다) | 떠 있는 편지 하나를 나타내는 유리병 | 기본: 가볍게 떠 있음 / 눌림: 살짝 커짐 | 로딩·실패 시에는 표시하지 않고 상태 안내를 보여줌 |
| 필터 | 해당 없음 (검색·필터 기능이 없다) | 해당 없음 | 해당 없음 |
| 상태 안내 | 빈 바다: "아직 도착한 유리병이 없어요" / 빈 편지함: "편지가 없습니다" / 로딩: 스피너 / 실패: "불러오지 못했습니다" | 문구와 아이콘 | 실패 시 "다시 시도" 버튼 |

## 5. 검토

- [ ] 색만으로 상태를 구분하지 않는다. (보관=책갈피·"보관", 삭제=휴지통·"버리기" 문구 병기)
- [ ] 일반 텍스트의 명암비와 실제 읽기 편의를 확인한다. (특히 바다 그라데이션 위의 글자)
- [ ] 주요 조작 영역을 충분히 확보한다. Flutter의 48×48 논리 픽셀 권고를 참고한다.
- [ ] 큰 글자·긴 내용에서도 정보가 잘리지 않는지 검토한다. (긴 편지, 편지함 스크롤)

## 6. 적용 범위

이 문서는 시안과 후속 Flutter 구현의 입력이다. 특정 도구의 자동 동기화가 완료되었다는 뜻은 아니다. 시안의 CSS 픽셀과 Flutter의 논리 픽셀을 구분하여 적용한다.

## 8. 글자 크기와 스켈레톤 (2026-11-11 추가)

- 글자 크기 설정: 85% / 100% / 115% / 130% / 140%. 3장의 크기는 100% 기준이다. 130% 이상에서는 편지 하단 버튼을 위아래로 쌓고, 긴 글은 줄바꿈하거나 스크롤한다.
- 스켈레톤: 불러오는 동안 글자 자리에 둥근 막대(높이는 글자 크기를 따름)를 두고 빛이 왼쪽에서 오른쪽으로 지나간다. 바다에서는 흐린 유리병 세 개와 "유리병을 찾고 있어요…"를 보여 준다. 기기의 "움직임 줄이기"가 켜져 있으면 움직이지 않는다.
