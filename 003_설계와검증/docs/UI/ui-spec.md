기준 문서: `requirements.md`, `ui-flow.md`, `design-system.md`

## 2. S01 내 바다 (메인)

| 항목 | 내용 |
|---|---|
| 요구사항 | R01, R02, R03, R04, R05 |

| 진입 조건 | 로그인 성공 직후 또는 로그인 상태 유지. 진입할 때 서버에서 바다를 불러온다 |

| 완료 결과 | 보관·삭제한 유리병이 바다에서 사라진다. 발송 결과는 S03 보낸 편지함에서 확인한다 |

| 전체 자료 없음 | 빈 바다 안내("아직 도착한 유리병이 없어요") | 편지 쓰기(FAB) 또는 기다리기 | AC03 |
| 검색 결과 없음 | 해당 없음 (검색 기능이 없다) | 해당 없음 | 해당 없음 |

## 3. S02 편지 쓰기 (바텀시트, 등록 전용)

수정 모드는 없다. 편지는 한 번 보내면 수정할 수 없기 때문이다.

| 모드 | 제목 | 초기 값 | 저장 버튼 | 성공 후 결과 |
|---|---|---|---|---|
| 등록 | 편지 쓰기 | 받는 사람·내용 비어 있음, 익명 여부는 꺼짐(익명 아님) | 보내기 | 시트가 닫히고 S01로 돌아가 "보냈습니다" 안내. 보낸 편지함에 기록됨 |
| 수정 | 해당 없음 (편지는 수정할 수 없다) | 해당 없음 | 해당 없음 | 해당 없음 |

| 논리 이름 | 화면 라벨 | 입력 방식 | 필수 | 조건 | 오류 안내 |
|---|---|---|---|---|---|
| receiverUsername | 받는 사람 | 검색 입력 칸 + 검색 결과 목록에서 선택 (선택하면 선택된 사용자로 표시, 바꾸려면 다시 검색). 글자를 칠 때마다 검색하지 않고 입력이 1초간 멈추면 검색 | 필수 | 존재하는 아이디, 부분 일치, 대소문자 구분, 나 자신은 선택 불가. 결과에는 아이디만 표시 | "받는 사람을 선택해주세요." / "일치하는 사용자가 없습니다." / "나 자신에게는 보낼 수 없습니다." |
| content | 편지 내용 | 여러 줄 텍스트 | 필수 | 빈 내용 불가, 길이 제한 없음 | "편지 내용을 입력해주세요." |
| isAnonymous | 익명으로 보내기 | 스위치 | 선택 | 켜면 받는 사람이 발신자를 알 수 없음 | 해당 없음 |

| 상태·행동 | 동작 | 유지할 값 | 검증 기준 |
|---|---|---|---|
| 검색 대기·검색 중·검색 실패 | 입력 후 1초 동안은 "입력을 멈추면 검색해요…", 검색이 시작되면 "검색 중…"을 결과 영역에 표시. 검색어를 지우면 결과도 지움. 검색 중에 입력이 바뀌면 이전 결과는 버림. 실패하면 "검색하지 못했습니다"와 [다시 시도] | 입력한 모든 값 | AC05 |
| 입력 오류 | 해당 항목 바로 아래에 오류 문구 표시 | 입력한 모든 값 | AC05 |
| 저장 중 | [보내기]를 스피너로 바꾸고 입력과 버튼을 잠가 중복 제출 방지 | 입력한 모든 값 | AC10 |
| 저장 실패 | 실패 안내와 [다시 시도], 성공으로 표시하지 않음 | 입력한 모든 값 | AC10 |
| 변경 없이 취소 | 시트를 닫고 S01로 복귀. Android 뒤로 가기도 같다 | 자료 변경 없음 | AC07 |
| 변경 후 취소 | "작성 중인 편지를 버릴까요?" 폐기 확인 | 계속 작성이면 유지, 폐기하면 삭제 | AC07 |
| 대상 바다가 가득 참 | 발송은 성공으로 처리한다. 편지는 상대 바다의 대기열에 들어간다 | 해당 없음 | AC13 |

## 4. S00 공통 로그인 연결

로그인하지 않았거나 로그인이 만료되면 S00으로 보낸다. 로그인에 성공하면 S01 내 바다로 이동한다. 제공 화면을 연결하며, 별도 회원 가입·비밀번호 찾기는 이 문서의 설계 범위에 포함하지 않는다. 실제 인증 코드는 다음 단계에서 구현한다.

### S04 받은 편지함 (팝업)

| 항목 | 내용 |
|---|---|
| 요구사항 | R01, R04, R05 |
| 표시 정보 | 보관한 편지 목록: 보낸 사람(익명이면 "익명"), 보관일, 내용 앞부분. 길면 스크롤. 최근 순. 답장한 편지의 카드에는 맨 오른쪽에 체크 아이콘(보조 설명 "답장한 편지")을 표시하고, 답장하지 않은 카드에는 표시하지 않는다. 익명이 아닌 카드의 보낸 사람 이름은 밑줄과 색으로 눌러 볼 수 있음을 알리고, 누르면 그 사람의 바다(S07)로 간다 |
| 주요 행동 | 항목 선택 시 S05. 카드를 슬라이드하면 삭제(수신자 본인, 삭제 확인 없음). 닫기: 닫기 버튼, 팝업 바깥 터치, Android 뒤로 가기 |
| 슬라이드 삭제 | 목록 카드를 Dismissible로 감싼다. 슬라이드하는 동안 카드 뒤에 삭제 색과 휴지통 아이콘, "삭제" 문구를 보여준다. 서버에서 삭제가 확인된 뒤에만 카드를 지우고, 실패하면 카드가 제자리로 돌아오며 안내를 보여준다. 방향은 정하지 않았다 |
| 상태 | 정상 / 비어 있음("보관한 편지가 없습니다") / 로딩 / 읽기 실패와 [다시 시도] |
| 검증 기준 | AC02, AC03, AC08 |

### S06 답장 쓰기

| 항목 | 내용 |
|---|---|
| 요구사항 | R06, R05 |
| 진입 조건 | S05에서 바다에서 연 일반 편지의 [답장]을 누른다. 익명 편지, 받은 편지함·보낸 편지함의 편지에서는 들어올 수 없다 |
| 표시 정보 | 상단: 돌아가기 버튼과 제목("OOO 님에게 답장"). 본문: 편지지 모양의 답장 입력 칸. 하단: [답장 보내기]. 받는 사람은 원 발신자로 정해져 있어 고르지 않고, 답장에는 익명이 없다(Q14 확정) |
| 임시 저장 | 돌아가기(또는 Android 뒤로 가기)를 누르면 내용이 있을 때만 임시 저장하고 "작성한 답장을 임시 저장했어요" 안내를 보여준 뒤 S05로 돌아간다. 비어 있으면 저장하지 않는다 |
| 불러오기 | 임시 저장이 있는 편지에서 [답장]을 누르면 "임시 저장한 답장이 있어요. 불러올까요? 취소를 누르면 새로 씁니다."를 묻는다. 확인은 불러오기(내용을 채우고 "임시 저장한 답장을 불러왔어요" 표시), 취소는 빈 화면으로 새로 쓰기이며 이전 임시 저장은 그 자리에서 버린다(Q13 확정) |
| 완료 결과 | 보내면 S01로 돌아가 "답장을 보냈어요. 원래 편지는 받은 편지함에 보관했어요." 안내를 보여준다. 원본은 바다에서 사라지고 받은 편지함에 보관되며, 그 카드 맨 오른쪽에 체크 아이콘이 생긴다. 임시 저장은 지운다 |

| 상태·행동 | 동작 | 유지할 값 | 검증 기준 |
|---|---|---|---|
| 내용 비어 있음 | 입력 칸 아래에 "답장 내용을 입력해주세요." | 입력 | AC16 |
| 보내는 중 | 버튼을 스피너로 바꾸고 입력과 돌아가기를 잠가 중복 제출 방지 | 입력 | AC16 |
| 보내기 실패 | "보내지 못했습니다. 입력한 내용은 그대로 있어요." 안내와 재시도. 원본 편지는 바다에 그대로 있다 | 입력과 임시 저장 | AC16 |
| 돌아가기 | 임시 저장 후 S05 | 쓰던 내용(임시 저장) | AC17 |
| 불러오기 확인 | 확인은 불러오기, 취소는 새로 쓰기 | 확인: 임시 저장 내용 / 취소: 빈 내용 | AC17 |
| 이미 사라진 편지 | "이미 사라진 편지입니다" 안내 후 S01 갱신 | 해당 없음 | AC11 |

### S08 바다 공개 설정 (작은 창)

| 항목 | 내용 |
|---|---|
| 요구사항 | R07, R05 |
| 진입 조건 | 내 바다(S01) 좌상단의 바다 공개 칩을 누른다 |
| 표시 정보 | 제목 "내 바다 공개", 스위치 "바다 공개하기", 현재 상태 설명, [닫기] |
| 설명 문구 | 공개 중: "다른 사람이 내 아이디와 떠 있는 유리병 개수를 볼 수 있어요. 편지 내용은 볼 수 없어요." 비공개: "나만 내 바다를 볼 수 있어요." (기본은 비공개) |
| 동작 | 스위치를 바꾸면 스위치가 잠기고 스피너를 보여준 뒤, 서버가 확인한 값으로 스위치·설명·바다 화면의 칩을 바꾸고 "바다를 공개했어요."/"바다를 비공개로 바꿨어요." 안내를 보여준다 |
| 실패 | 설정은 그대로이고 "바꾸지 못했습니다. 설정은 그대로예요. 다시 시도해주세요."를 보여준다(AC20) |

## 6. 시스템 관리 자료와 인계

| 논리 이름 | 의미 | 화면 입력과의 구분 |
|---|---|---|
| id | 편지 식별자 | 사용자가 직접 입력하지 않음 |
| senderId | 발신자 식별자 | 인증된 사용자와 연결할 자료. 익명 편지에서도 수신자에게 노출하지 않음 |
| receiverId | 수신자 식별자 | 입력한 받는 사람 아이디로 결정되는 자료 |
| deliveryStatus | 편지 상태 | 서버가 관리하는 자료. 사용자가 고르지 않음 |
| sentAt, expiresAt | 발송·만료 시각 | 발송 시 서버가 기록하는 자료 |
| archivedAt | 보관 시각 | [보관] 시 서버가 기록하는 자료 |
| createdAt | 생성 시각 | 생성 시 관리할 자료 |
| isReplied | 답장 여부 | 답장을 보낸 서버 처리에서 정해지는 자료. 받은 편지함 카드의 체크 아이콘으로 보여준다 |
| replyDraft | 임시 저장한 답장 | 사용자가 쓴 내용이지만 돌아가기 때 자동으로 저장되는 자료. 편지를 열어 둔 동안만 보관하고, 그 편지가 답장·보관·버리기·열람 후 이탈로 사라지면 함께 지운다. 서버에 보내지 않는다(Q12 확정) |

DB 자료형·테이블·API URL은 이 문서에서 확정하지 않는다.

## 7. 설정 서랍과 네트워크 끊김 (2026-11-11 추가)

### 설정 서랍 (S01 좌상단 메뉴)

| 항목 | 내용 |
|---|---|
| 내 바다 공개 설정 | S08을 연다 |
| 바다 색감 | 아침바다(기본) / 밤바다 / 기기 설정. 고르면 바로 바뀌고 사용자별로 서버에 저장한다 |
| 글자 크기 | 슬라이더 다섯 단계(85~140%, 기본 100%)와 미리 보기. 바꾸면 바로 반영하고 사용자별로 서버에 저장한다 |
| UI 숨김 대기 시간, 파도 종류 | 동작은 이전과 같고, 이 값도 사용자별로 서버에 저장한다 |
| 설정 저장 실패 | "설정을 서버에 저장하지 못했어요. 다음에 로그인하면 이전 설정으로 보여요." 안내. 화면에는 이번 실행 동안 바꾼 값이 남는다 |
| 로그아웃·다른 사용자 로그인 | 로그아웃하면 화면이 기본값(아침바다, 100%)으로 돌아가고, 로그인하면 그 사용자의 설정을 불러온 뒤 바다로 들어간다 |
| 로그아웃 | 서랍 맨 아래에 고정한다(목록을 내리지 않아도 보인다) |
